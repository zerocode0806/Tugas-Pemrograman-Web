Kategori Istilah Web

Istilah dalam pengembangan web dikelompokkan berdasarkan fungsi dan penggunaannya agar lebih mudah dipahami. Setiap kategori memiliki deskripsi dan istilah yang berkaitan.

  • Frontend

    Frontend adalah bagian dari website yang berinteraksi langsung dengan pengguna. Frontend mengatur struktur, tampilan, dan interaksi halaman web.

    • Bahasa Pemrograman dan Markup

      Bahasa dan markup digunakan untuk membangun struktur serta mengatur tampilan halaman web.

      • HTML — bahasa markup untuk menyusun struktur halaman web.
      • CSS — bahasa stylesheet untuk mengatur warna, ukuran, dan tata letak.
      • JavaScript — bahasa pemrograman untuk membuat halaman web interaktif.
    • Konsep

      Konsep frontend membantu membuat website yang nyaman digunakan pada berbagai perangkat.

      • Responsive Design — teknik menyesuaikan tampilan dengan ukuran layar.
      • Aksesibilitas — prinsip membuat website dapat digunakan oleh berbagai pengguna, termasuk penyandang disabilitas.
  • Backend

    Backend merupakan bagian website yang bekerja di sisi server. Bagian ini menangani logika aplikasi, pengolahan data, autentikasi, dan komunikasi dengan database.

    • Bahasa Pemrograman

      Bahasa backend digunakan untuk menjalankan logika aplikasi dan memproses permintaan pengguna.

      • PHP — bahasa pemrograman yang banyak digunakan untuk pengembangan web.
      • Python — bahasa pemrograman yang dapat digunakan untuk membangun layanan dan aplikasi web.
    • Layanan

      Layanan backend menghubungkan aplikasi dengan data dan menyediakan fungsi yang dibutuhkan oleh frontend.

      • API — antarmuka yang memungkinkan aplikasi saling berkomunikasi.
      • Server — sistem yang menerima permintaan dan memberikan respons kepada klien.
  • Database

    Database atau basis data adalah sistem penyimpanan informasi yang terorganisasi sehingga data dapat dikelola, dicari, diperbarui, dan digunakan kembali.

    • MySQL

      MySQL merupakan sistem manajemen basis data relasional yang menggunakan SQL untuk mengelola data dalam tabel.

      • Tabel — struktur yang menyimpan data dalam baris dan kolom.
      • Query — perintah untuk mengambil atau memanipulasi data.
  • Deployment

    Deployment adalah proses menempatkan aplikasi website pada lingkungan server agar dapat diakses oleh pengguna melalui jaringan internet.

    • Domain

      Domain merupakan nama alamat website yang digunakan pengguna untuk mengakses sebuah situs.

    • Hosting

      Hosting adalah layanan yang menyediakan sumber daya server untuk menyimpan file dan menjalankan website agar dapat diakses secara online.

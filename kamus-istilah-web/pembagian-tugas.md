# Pembagian Tugas Proyek Kamus Istilah Web

## Tujuan

Setiap anggota mengerjakan **satu halaman website** sesuai pembagian
tugas. Kerjakan isi halaman dan CSS masing-masing terlebih dahulu agar
setiap anggota memahami kode HTML dan CSS yang dibuat. CSS akan
digabungkan dan dirapikan bersama pada tahap akhir.

## Pembagian Tugas

### 1. Beranda --- Ubed

- **Folder:** `Ubed/`
- **File HTML:** `index.html`
- **File CSS:** `style.css`
- **Tugas:** Membuat isi halaman beranda, misalnya pengenalan Kamus
  Istilah Web, penjelasan singkat fungsi website, dan petunjuk
  penggunaan.
- **Catatan:** Header, navigasi, dan footer awal sudah tersedia.
  Lanjutkan kode pada bagian isi halaman tanpa menghapus bagian yang
  sudah diberikan.

### 2. Glosarium --- Agung

- **Folder:** `Agung/`
- **File HTML:** `glosarium.html`
- **File CSS:** `style.css`
- **Tugas:** Membuat daftar istilah web beserta pengertian singkatnya.
  Susun agar mudah dibaca, misalnya menggunakan daftar, tabel, atau
  kartu istilah.
- **Catatan:** Header, navigasi, dan footer awal sudah tersedia. Fokus
  pada isi glosarium dan tampilan khusus halaman ini.

### 3. Kategori --- Dedi

- **Folder:** `Dedi/`
- **File HTML:** `kategori.html`
- **File CSS:** `style.css`
- **Tugas:** Menampilkan kategori istilah web, misalnya HTML, CSS,
  JavaScript, jaringan, dan basis data. Berikan deskripsi singkat
  untuk setiap kategori.
- **Catatan:** Header, navigasi, dan footer awal sudah tersedia. Fokus
  pada isi kategori dan tata letaknya.

### 4. About/Tentang --- Ihya

- **Folder:** `Ihya/`
- **File HTML:** `about.html`
- **File CSS:** `style.css`
- **Tugas:** Membuat halaman tentang proyek, tujuan pembuatan Kamus
  Istilah Web, serta informasi anggota kelompok bila diperlukan.
- **Catatan:** Header, navigasi, dan footer awal sudah tersedia. Fokus
  pada isi halaman tentang.

## Ketentuan Pengerjaan

1.  Kerjakan hanya halaman yang menjadi tanggung jawab masing-masing.
2.  Gunakan file HTML dan `style.css` yang sudah tersedia di folder
    masing-masing.
3.  **Jangan menghapus atau mengubah struktur header, navigasi, dan
    footer awal** kecuali sudah disepakati bersama.
4.  Tambahkan isi halaman pada bagian yang diberi komentar
    `Lanjutkan kode untuk isi halaman`.
5.  Buat CSS untuk isi halaman masing-masing di file `style.css`. Untuk
    sementara, CSS boleh dibuat terpisah agar mudah dipelajari dan
    diperiksa.
6.  Gunakan HTML yang rapi, penamaan class yang jelas, serta elemen
    semantik jika sesuai.
7.  Pastikan halaman tetap nyaman dibaca di layar komputer maupun
    ponsel.
8.  Hindari mengubah pekerjaan anggota lain tanpa koordinasi.
9.  Sebelum dikumpulkan, pastikan halaman HTML dan CSS masing-masing
    berjalan dengan benar.

## Catatan Penting tentang Nama File dan Navigasi

Tautan navigasi pada kode awal menggunakan nama `istilah.html` dan
`tentang.html`, sedangkan pembagian tugas di atas menggunakan
`glosarium.html` dan `about.html`.

Agar tautan tidak rusak, **samakan nama file dengan tautan navigasi
sebelum proyek digabungkan**. Kelompok dapat memilih salah satu cara: -
Menggunakan nama file sesuai pembagian tugas (`glosarium.html` dan
`about.html`), lalu memperbarui tautan navigasi; atau - Tetap
menggunakan nama file pada kode awal (`istilah.html` dan `tentang.html`)
dan menyesuaikan nama file pada pembagian tugas.

Perhatikan juga lokasi file CSS. Karena setiap anggota memiliki folder
sendiri, pastikan nilai `href` pada elemen `<link rel="stylesheet">`
mengarah ke `style.css` yang benar di folder tersebut. Sesuaikan
jalurnya dengan struktur repositori dan cara website dijalankan.

**Intinya:** setiap anggota bertanggung jawab atas satu halaman beserta
CSS-nya. Kerjakan secara mandiri terlebih dahulu, lalu satukan dan uji
hasilnya bersama-sama.

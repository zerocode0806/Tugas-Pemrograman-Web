Glosarium

Daftar 11 kamus istilah web, dikelompokkan menurut kategori.

FRONTEND

HTML

HyperText Markup Language; bahasa markup untuk membentuk struktur halaman web.

Contoh: Halaman web dibuat menggunakan HTML.
CSS

Cascading Style Sheets; bahasa untuk mengatur tampilan, warna, ukuran, dan tata letak halaman.

Contoh: Pengembang memakai CSS untuk mengatur tampilan halaman.
JavaScript

Bahasa pemrograman untuk membuat web interaktif dan lebih dinamis.

Contoh: JavaScript membuat tombol pada website berfungsi.

BACKEND

API

Application Programming Interface; antarmuka agar suatu perangkat lunak dapat berkomunikasi dengan perangkat lunak lain.

Contoh: Aplikasi memakai API untuk mengambil data dari server.
Backend

Bagian aplikasi yang menangani proses, logika program, dan pengolahan data.

Contoh: Data pengguna diproses oleh sistem backend.
Server

Komputer atau sistem yang menyediakan data dan layanan kepada perangkat lain melalui jaringan.

Contoh: Website yang sudah dihosting berjalan menggunakan server.

DATABASE

Database

Kumpulan data yang disimpan secara terstruktur.

Contoh: Data mahasiswa disimpan dalam database.
MySQL

Sistem manajemen basis data relasional untuk menyimpan dan mengelola data.

Contoh: Aplikasi absensi menggunakan MySQL untuk menyimpan data.

LAINNYA

Domain

Nama unik untuk mengakses sebuah website melalui internet.

Contoh: example.com merupakan nama domain sebuah website.
Hosting

Layanan yang menyediakan tempat untuk menyimpan file website agar dapat diakses melalui internet.

Contoh: File website disimpan pada layanan hosting.
Framework

Kerangka kerja yang menyediakan struktur dan komponen untuk membantu pengembangan aplikasi.

Contoh: Laravel merupakan framework untuk pengembangan web.

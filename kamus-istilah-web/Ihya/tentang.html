TENTANG KAMI

Mengenal List dalam HTML, Terstruktur dan Mudah Dipahami

Website ini membahas penggunaan elemen list dalam HTML, mulai dari daftar berurutan, daftar tidak berurutan, daftar deskripsi, hingga menu. Pelajari fungsi dan contoh penerapannya dalam pembuatan website.

PENGGUNAAN MENU

    •

    Implementasi Kelompok List

    1. Ordered list (ol) pada index.html: tujuan dan manfaat kamus, memakai type, start, dan reversed.
    2. Unordered list (ul) pada kategori.html: kategori bersarang 2 tingkat.
    3. Description list (dl) pada istilah.html: glosarium 11 istilah.
    4. Menu (menu) pada tentang.html: daftar tombol perintah.

    Pembagian Tugas Kelompok

    Website Kamus Istilah Web ini dikembangkan secara berkelompok sebagai media pembelajaran pemrograman web.

    Anggota File Elemen
    Ubed index.html ol
    Agung istilah.html dl
    Deddy kategori.html ul
    Ihya tentang.html menu
